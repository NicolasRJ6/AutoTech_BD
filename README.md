# AutoTech_BD
# Sistema de Remuneraciones AutoTech 🚗🔧

Este es mi proyecto para la Evaluación 2 de la asignatura Taller de Base de Datos (BDY1103)[cite: 2, 3].

## ¿De qué trata?
Es un sistema hecho en Oracle PL/SQL (versión 21c) para automatizar el cálculo de sueldos y bonos de los mecánicos del taller "AutoTech"[cite: 2]. El objetivo era dejar de calcular las comisiones a mano y pasar a un modelo automático, rápido y con registro de auditoría.

## Archivos del proyecto
* `Automech.sql`: Contiene todo el script de la base de datos (creación de tablas, Funciones, Procedimientos, un Package público/privado y los Triggers de auditoría).
* `InformeBD.docx`: El informe técnico explicando cómo funciona el código, el uso de cursores complejos y las decisiones que tomé.
* `PPTBaseDeDatosND.pptx`: La presentación de apoyo para explicar el código y mostrar que el cierre de mes ahora toma solo fracciones de segundo.
